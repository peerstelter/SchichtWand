# SchichtWand

**Kiosk-Webapp für Schichtplanung & Teamkommunikation**

SchichtWand ist eine produktionsreife Web-App für den Kiosk-Einsatz in Betrieben mit Schichtbetrieb. Mitarbeiter sehen ihren Dienstplan, aktuelle Infos und Ankündigungen auf einem zentralen Display — ohne Login, ohne App.

---

## Features

- **Kiosk-Modus** — vollbild-optimiert, touch-fähig, kein Browser-UI sichtbar
- **Schichtplan-Ansicht** — tages- und wochenbasierte Darstellung der aktuellen Besetzung
- **Schwarzes Brett** — Ankündigungen und Infos zentral verwalten und anzeigen
- **Admin-Panel** — Schichten, Mitarbeiter und Inhalte über Web-Interface pflegen
- **Offline-fähig** — läuft auch ohne dauerhaft stabile Netzwerkverbindung
- **Responsiv** — optimiert für Tablets und Displays in verschiedenen Formaten
